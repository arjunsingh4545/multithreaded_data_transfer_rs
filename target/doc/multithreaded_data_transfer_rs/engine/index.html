Module engine 

Source
Expand description

Running a copy: Engine::prepare decides, Engine::execute copies.

The engine is generic over its OS seams (device probe, I/O hints, extent locator). Default type parameters give production behaviour with Engine::new(), while tests inject fakes through Engine::with_parts.
