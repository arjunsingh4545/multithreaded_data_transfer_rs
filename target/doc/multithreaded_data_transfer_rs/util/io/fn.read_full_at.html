pub fn read_full_at(file: &File, buf: &mut [u8], offset: u64) -> Result<usize>
Expand description

Reads at offset until buf is full or the file ends, retrying on EINTR.

Returns the number of bytes read; a value shorter than buf.len() means end of file. (Unlike FileExt::read_exact_at, reaching EOF early is not an error.)
