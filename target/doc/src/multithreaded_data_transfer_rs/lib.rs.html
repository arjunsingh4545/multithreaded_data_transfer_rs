1//! Disk-aware directory copy.
2//!
3//! The crate picks a copy strategy based on the kind of disk on each side:
4//! many concurrent copies for SSDs, and a sequential reader → writer pipeline
5//! with large buffers when a rotational disk is involved.
6//!
7//! # Layers
8//!
9//! | module       | role                                                    |
10//! |--------------|---------------------------------------------------------|
11//! | [`cli`]      | terminal input/output only (clap, progress bars)        |
12//! | [`engine`]   | runs a copy: prepare → scan → order → execute           |
13//! | [`domain`]   | pure types and decisions, no I/O                        |
14//! | [`platform`] | OS adapters; the only home of `libc` and `unsafe`       |
15//! | [`util`]     | small helpers that know nothing about copying           |
16//!
17//! Each layer depends only on the layers below it.
18//!
19//! # Example
20//!
21//! ```no_run
22//! use multithreaded_data_transfer_rs::{CopyRequest, Engine, NoProgress};
23//! use tokio_util::sync::CancellationToken;
24//!
25//! let engine = Engine::new();
26//! let prepared = engine.prepare(&CopyRequest::new("/mnt/a", "/mnt/b"), &NoProgress)?;
27//! println!("{}", prepared.plan());
28//! let summary = engine.execute(&prepared, &NoProgress, &CancellationToken::new())?;
29//! println!("copied {} files", summary.stats.files);
30//! # Ok::<(), multithreaded_data_transfer_rs::Error>(())
31//! ```
